### 📝 Formulario y Resultados con Web Components
Este proyecto es una aplicación web simple que utiliza Web Components para crear un formulario interactivo. Al enviar el formulario, los datos ingresados se muestran en una sección de resultados, y el formulario desaparece. 🚀

### ✨ Características
- 📄 Formulario interactivo: Permite al usuario ingresar su nombre, edad, correo electrónico, dirección y hobbies.

- 📊 Resultados dinámicos: Muestra la información ingresada en una sección de resultados después de enviar el formulario.

- 📱 Diseño responsivo: Se adapta a diferentes tamaños de pantalla, incluyendo dispositivos móviles.

- 🧩 Web Components: Utiliza elementos personalizados (<formulario-element> y <elidallana-element>) para encapsular la lógica y el estilo.

### 🛠️ Tecnologías utilizadas
- 📄 HTML: Estructura del proyecto.

- 🎨 CSS: Estilos y diseño responsivo.

- ⚙️ JavaScript: Lógica del formulario y creación de Web Components.

### 🚀 Cómo usar
Clona el repositorio:

````bash
git clone https://github.com/tu-usuario/tu-repositorio.git
````
- Abre el archivo index.html en tu navegador.

- Completa el formulario y haz clic en "Enviar".

- Observa cómo el formulario desaparece y se muestra la información ingresada. 🎉
